A few things to know

Three modes, no automatic repricing

Store pricing uses your locked reference and works offline after the hosted app has been cached. Live estimate requires a successful, fresh, timestamped quote. What-if uses your manually entered gold scenario.

The formula

Replacement per gram = (gold per troy oz / 31.1034768) × (karat / 24) × (1 + supplier premium / 100).

Adjusted rate = saved base retail rate + replacement per gram now − replacement per gram at calibration. Charge the first-tier grams at the first rate and only the additional grams at the lower rate. Round the total up.

Live-data safeguards

The app requests Gold API's USD XAU quote about every 60 seconds while visible, then tries XAUS if the first source fails or is stale. Gold API requests are spaced by at least 30 seconds; XAUS requests by at least 60 seconds. Each request has a seven-second timeout. Provider timestamps and explicit stale flags determine freshness, never a newly generated response time alone. XAUS is a backup connection, not a guarantee of an independent upstream source. An old, failed or offline quote never silently becomes a live calculation. Connection details are visible above. Quotes are indicative, not settlement or trade-execution prices.

Premium and profit

Premium estimates supplier costs above intrinsic gold. It is not your retail margin. Amount above replacement is before fees, service, warranty, overhead and tax. This app does not establish realized profit or demand.

Install & privacy

Once hosted on HTTPS, use your browser's Install app option, or Share → Add to Home Screen on a supporting phone. Local HTML files can calculate, but cannot install as an offline PWA.

Settings and cached quotes stay in this browser. They do not sync across devices. No inventory, customer records or analytics are included. Gold API and, when used, XAUS receive network requests and standard connection information; item weights, premiums, historical cost and calculated prices are not sent.

This version has no login. Hosting source in a private GitHub repository does not by itself make a Pages website private. Noindex is not access control. Do not publish confidential records or API secrets. Choose authenticated hosting before publishing an internal-only tool.
